🫀 CardioPulse
AI-Powered Hypertension Risk Assessment System
CardioPulse is a Machine Learning-based web application designed to assess hypertension risk using clinical and lifestyle-related patient information.
The system uses a trained K-Nearest Neighbors (KNN) classification model to analyze patient parameters and predict their hypertension stage. The model is integrated with a Python backend and a web-based frontend to provide real-time predictions.
The project demonstrates an end-to-end Machine Learning workflow — from patient data processing and model training to deployment through a web interface.

🧠 Machine Learning
CardioPulse uses K-Nearest Neighbors (KNN) for hypertension classification.
The model was trained using patient-related clinical and lifestyle parameters and saved as a serialized `.pkl` file for use during prediction.
Model
Algorithm: K-Nearest Neighbors (KNN)
Model File:
```text
knn_model.pkl
```
The trained model is loaded by the backend and used to generate predictions based on the information submitted through the web interface.

⚙️ Installation
1. Clone the repository
```bash
git clone https://github.com/arunreddy7-alt/cardiopulse.git
```
2. Navigate to the project
```bash
cd cardiopulse
```
3. Create a virtual environment
```bash
python -m venv venv
```
4. Activate the environment
Windows
```bash
venv\Scripts\activate
```
macOS / Linux
```bash
source venv/bin/activate
```
5. Install dependencies
```bash
pip install -r requirements.txt
```
---
▶️ Running the Application
Run the Flask application:
```bash
python app.py
```
The application will start on the local Flask server.
Open the URL shown in the terminal in your browser and enter the required patient information.
